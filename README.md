# Sisters' Dresses — проект сайта

Владелец: Ирина, бренд Sisters' Dresses (Дананг, Вьетнам). Домен: sistersdresses.club (куплен в GoDaddy).
Планируемый хостинг: Cloudflare Pages (бесплатный, статический сайт).

## Правила работы
- Изменения вносить и показывать Ирине (скриншот / текст). Публиковать на сайт ТОЛЬКО по её команде «публикуй».
- Фото не сжимать: в `images/` лежат файлы в лучшем доступном качестве. Оригиналы у Ирины в телефоне.
- Общаться с Ириной по-русски, коротко: она работает с телефона.

## Устройство
- `index.html` — весь сайт (страницы, стили, скрипт, тексты на русском/английском/вьетнамском).
- `images/` — фотографии. В CSS они подключены переменными `--i-<имя>` (например `--i-vc01`), логотипы — `--l-...`.
- Страницы задаются хэш-маршрутами (`#/victoria`, `#/olga`, `#/middle` ...). Товары — в объекте с описанием
  (title, back, imgs, variants, texts, setlist, predict); переводы — в трёх блоках i18n (ru/en/vi).
- Новый товар = запись в объекте товаров + плитка на странице сестры + маршрут в регулярном выражении + ключи перевода.
